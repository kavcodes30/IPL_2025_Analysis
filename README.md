# 🏏 IPL 2025 Performance Analysis — Decoding RCB’s Winning Formula

## Overview

This project is a complete data analysis and storytelling journey based on the IPL 2025 season. Using Python and data visualization libraries, the project explores how teams and players performed throughout the tournament while uncovering the strategic patterns that helped Royal Challengers Bengaluru (RCB) dominate the season.

Instead of only presenting numbers, this project focuses on telling the story hidden inside the data:

* Which batters controlled the season?
* Did aggressive strike rates actually translate into wins?
* Which bowling attacks consistently created pressure?
* What separated RCB from the rest of the league?
* How did balance between batting firepower and bowling discipline become RCB’s biggest strength?

The project combines statistical analysis, exploratory data analysis (EDA), feature engineering, and visual storytelling to transform raw IPL data into meaningful cricket insights.

---

# 📖 The Story Behind the Analysis

IPL seasons are often remembered through moments — explosive sixes, game-changing spells, clutch partnerships, and dramatic finishes.

But behind every championship run lies a deeper story written in data.

This project began with a simple question:

> "What made RCB so effective during IPL 2025?"

To answer that question, the analysis moves through multiple layers:

1. Understanding overall batting dominance across the league
2. Identifying the most destructive and consistent batters
3. Evaluating bowling efficiency and wicket-taking ability
4. Comparing team-level batting and bowling metrics
5. Measuring RCB’s performance against league averages
6. Discovering the balance between aggression and control

By the end of the analysis, a clear pattern emerges:

RCB’s success was not built on one superstar performance alone.

It came from:

* High strike-rate batting
* Consistent run production
* Effective wicket-taking bowlers
* Better economy management
* Team-wide balance across departments

The data shows that RCB maintained an aggressive batting approach while still sustaining bowling discipline — a combination that made them one of the most complete teams of the tournament.

## 🏆 RCB’s Winning Strategy — What the Data Revealed

The most important part of this project was understanding *why* RCB performed so well.

### 📌 Strategy 1 — Aggressive Batting Philosophy

RCB maintained a strong team strike rate compared to league averages.

This suggested:

* Intent-based batting
* Faster scoring in middle overs
* Better pressure handling
* Ability to accelerate consistently

---

### 📌 Strategy 2 — Balanced Team Contribution

The analysis showed that RCB’s success did not rely on a single player.

Instead:

* Multiple batters contributed meaningful runs
* Bowlers collectively shared wicket-taking responsibilities
* The team performed consistently across departments

This balance reduced overdependence on individual performances.

---

### 📌 Strategy 3 — Strong Bowling Control

RCB bowlers maintained competitive economy rates while still taking wickets.

This combination is extremely important in T20 cricket because:

* Wickets create pressure
* Lower economy restricts momentum
* Controlled middle overs increase win probability

The data highlighted that RCB’s bowling attack was both aggressive and disciplined.

---

### 📌 Strategy 4 — Impact-Oriented Cricket

Custom “Impact” metrics were created for both batters and bowlers.

#### Batter Impact Formula

```python
Impact = Runs × (Strike Rate / 100)
```

#### Bowler Impact Formula

```python
Impact = (Wickets × 2) - Economy
```

These formulas helped identify players who influenced matches beyond traditional statistics.
